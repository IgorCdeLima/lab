# BUG-T0010-01 - PNG de 16 bits em escala de cinza e aceito e gravado todo branco

## Como reproduzir

1. Gerar com o Pillow 12.3.0 um PNG em escala de cinza de 16 bits: `Image.new("I;16", (4, 4), 30000).save(buf, "PNG")` (o Pillow reabre esse arquivo como modo `I;16`).
2. Enviar em `POST /produtos` com campos validos (ou chamar `imagens.processar_imagem(buf.getvalue())`).
3. Reabrir o arquivo gravado e ler o pixel `(0, 0)`.

Tambem com um gradiente de 16 bits (`Image.linear_gradient("L")` escalado x257 e salvo como `I;16`): o arquivo gravado tem **1** valor distinto (esperado ~256).

## Esperado

A imagem e aceita (303) e gravada com o mesmo conteudo visual: cinza ~117 para o valor 30000 (30000/65535 x 255), ou o PNG mantido em 16 bits.

## Obtido

303, e o arquivo gravado e `PNG RGB` com **todos os pixels (255, 255, 255)**, para os valores 1000, 30000 e 65535. A imagem do usuario se perde em silencio: nenhuma mensagem e o produto aparece com um quadrado branco.

## Evidencia

Medido no commit `0192e03`, imagem `test` do projeto `t0010-rev`, chamando `app.imagens.processar_imagem`:

```
entrada I;16 30000 abre como I;16 30000
   gravado RGB (255, 255, 255) esperado ~ 117
entrada I;16 1000 abre como I;16 1000
   gravado RGB (255, 255, 255) esperado ~ 4
gradiente 16 bits: valores distintos no gravado = 1 (esperado ~256)
```

Na aplicacao rodando (`APP_PORT=8110 docker compose -p t0010-rev`): `PNG 16 bits (I;16)` -> 303, gravado `PNG RGB (32, 32)`.

## Causa raiz

`_modo_para` em `app/imagens.py`: para PNG, os modos aceitos sem conversao sao `1`, `L`, `RGB`, `RGBA` e `LA`; `I;16` cai em `im.convert("RGB")`, que no Pillow satura os valores de 16 bits (nao reescala para 8 bits). Nenhum teste cobre PNG de 16 bits (os testes de modo cobrem RGBA, P com transparencia, `1`, CMYK do JPEG).

Correcao possivel (decisao do Dev): manter `I;16` no PNG (o Pillow grava `I;16` como PNG de 16 bits) ou reescalar para `L` antes de converter (`v / 257`). Teste: PNG `I;16` com gradiente -> gravado preserva os niveis (ou os valores em 16 bits).
