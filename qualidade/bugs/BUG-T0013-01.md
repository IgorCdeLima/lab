# BUG-T0013-01 - requisitos.md ainda diz que a CSP tem 'unsafe-inline' em style-src

## Como reproduzir

1. No branch `T-0013` (commit `4f7b9db` ou posterior): `grep -n "unsafe-inline" docs/requisitos/requisitos.md`.

## Esperado

Depois da T-0013, nenhuma linha de `docs/requisitos/requisitos.md` deve afirmar que a CSP permite `'unsafe-inline'` (a CSP em `app/main.py` e `style-src 'self'; script-src 'self'`).

## Obtido

O Dev atualizou a linha 103 (notas da T-0012) e o RNF-08 da linha 115, mas deixou logo abaixo, na secao "Notas de implementacao (T-0007)", a linha 116:

```
- `'unsafe-inline'` so em `style-src`, porque o CSS esta num `<style>` do template; remover quando o CSS for para arquivo.
```

Ela contradiz a linha anterior (RNF-08 com os valores exatos, sem `'unsafe-inline'`).

## Evidencia

```
docs/requisitos/requisitos.md:103:- Desde a T-0013 o CSS e o JS ficam em arquivos (...) e a CSP nao tem mais `'unsafe-inline'`. (...)
docs/requisitos/requisitos.md:116:- `'unsafe-inline'` so em `style-src`, porque o CSS esta num `<style>` do template; remover quando o CSS for para arquivo.
```

## Causa raiz

Atualizacao parcial da documentacao no commit `4f7b9db` (regra do projeto: documentacao no mesmo commit da mudanca). Correcao sugerida: marcar a linha 116 como historica, por exemplo "(T-0007; superado na T-0013: o CSS foi para arquivo e o `'unsafe-inline'` saiu)", sem apagar o registro.
