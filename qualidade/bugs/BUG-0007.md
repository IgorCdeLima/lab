# BUG-0007 - Comentario do estagio "dev" no Dockerfile descreve a imagem errada

## Como reproduzir

1. Ler `Dockerfile`, bloco de comentario acima de `FROM base AS dev`: "A imagem so leva app/ e requirements.txt; nada de tests/ nem requirements-dev.txt."
2. `docker compose -p t0004-rev run --rm --no-deps test sh -c "ls /code"`.

## Esperado

O comentario descreve o estagio em que esta (dev) ou fica junto do estagio `runtime`, a que ele se refere.

## Obtido

A imagem do estagio dev leva `requirements-dev.txt` (copiado pelo proprio estagio) e, em execucao, `tests/` (volume):

```
app
requirements-dev.txt
requirements.txt
tests
```

A frase vale para a imagem `runtime`, mas esta escrita no bloco do `dev`. Quem ler o Dockerfile pode concluir que o estagio dev nao tem `requirements-dev.txt`.

## Evidencia

Saida acima (commit `63c7dcc`). A imagem `runtime` (servico `app`) mostra so `app` e `requirements.txt`, como o comentario diz.

## Causa raiz

A frase sobre a imagem de execucao foi colocada no bloco de comentario do estagio `dev`.

Correcao sugerida: mover a frase para o comentario de `FROM base AS runtime`, ou reescreve-la como "A imagem runtime so leva...".
